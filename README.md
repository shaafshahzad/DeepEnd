## Overview

DeepEnd helps aspiring developers move from vague learning goals to concrete software projects. Users answer a short survey about their experience, interests, and goals, then receive project recommendations with technical timelines they can follow step by step.

Built for the McMasterU Google Solutions Challenge, where it won first place.

## Highlights

- Personalized project recommendations based on user goals and experience level
- Step-by-step technical timelines with implementation guidance
- Code snippets and markdown explanations for each project milestone
- Progress tracking for saved project paths
- Firebase-backed authentication and persistence

## Stack

- Next.js
- TypeScript
- React
- Firebase
- OpenAI API
- Tailwind CSS
- Vercel

## Local Development

```bash
npm install
npm run dev
```

Create `.env.local` with the required Firebase and OpenAI credentials before running the app locally.
